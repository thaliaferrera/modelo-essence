# Modelo Essence

You are an award-winning UI/UX designer specializing in premium psychology websites.

Create a completely original website for a modern psychology clinic called Essence.

The website should immediately make visitors feel calm, emotionally safe and welcomed.

Do not create a generic psychology website.

Think like an interior designer creating a peaceful environment.

--------------------------------------------------

STYLE

Organic Minimalism

Soft Luxury

Natural

Elegant

Calm

Editorial

Human

--------------------------------------------------

COLOR PALETTE

Warm White (#FAF8F5)

Soft Sage Green (#DDE8DF)

Light Olive (#C9D8C5)

Sand Beige (#EEE8DD)

Dark Charcoal (#2E2E2E)

--------------------------------------------------

VISUAL LANGUAGE

Use organic shapes.

Rounded sections.

Natural curves.

Very generous spacing.

Subtle paper texture.

Beautiful photography.

Natural light.

Minimal icons.

Elegant typography.

--------------------------------------------------

Create subtle botanical details throughout the website.

Small eucalyptus branches.

Minimal olive leaves.

Fine line botanical illustrations.

Leaves should move very gently while scrolling, creating a calming feeling, almost like a soft breeze.

The animations must remain elegant and discreet.

--------------------------------------------------

HERO

Large calming image.

Headline:

"Um espaço seguro para cuidar da sua saúde emocional."

Subheadline:

Psychological care based on empathy, respect and listening.

Buttons:

Agendar Sessão

WhatsApp

--------------------------------------------------

SECTIONS

About

Therapeutic Approaches

Who Therapy Is For

Benefits

Testimonials

FAQ

Contact

Footer

--------------------------------------------------

ANIMATIONS

Slow fade-in

Gentle floating elements

Soft botanical movement

Elegant hover effects

Organic transitions

Nothing exaggerated.

--------------------------------------------------

Photography should feel authentic.

Natural light.

Wood textures.

Plants.

Comfortable chairs.

Books.

Warm interiors.

Avoid fake smiling stock photos.

--------------------------------------------------

The website should feel like entering a peaceful therapy office.

Every section should encourage visitors to stay.

Every visual decision should reduce anxiety.

--------------------------------------------------

IMPORTANT

All visible text must be written in Brazilian Portuguese (pt-BR).

Do not use English anywhere on the website.

Do not generate a template.

Create a premium, emotionally engaging experience that feels custom designed by a luxury creative agency.

The website must be visually unforgettable while remaining calm, elegant and deeply human.
